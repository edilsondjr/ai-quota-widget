# Quota Widget (pt-BR)

[English](../README.md) · [Español](README.es.md)

Widget flutuante para Windows que reúne as quotas de uso das suas IAs em um só lugar, com barras e contagem regressiva até a renovação. Hoje suporta **Claude**, **ChatGPT (Codex)**, **Command Code** e **Ollama**, e novos provedores são bem-vindos.

- **Instalar:** baixe o `Quota-Widget-Setup-<versão>.exe` na página de [Releases](https://github.com/edilsondjr/ai-quota-widget/releases). O instalador não é assinado, então o SmartScreen pode avisar; clique em "Mais informações" e "Executar assim mesmo".
- **Configurar:** clique no ⚙ do widget para escolher o que aparece, o intervalo de atualização, as chaves de API (guardadas criptografadas pelo Windows), o idioma (English/Español/Português) e o início com o Windows.
- **Gerar do código:** `npm install` e `npm run dist` (Node 20+, no Windows).
- **Aviso:** as rotas usadas não são oficiais e podem mudar. Use apenas com as suas próprias contas e por sua conta e risco.

A documentação completa (em inglês) está no [README](../README.md).
