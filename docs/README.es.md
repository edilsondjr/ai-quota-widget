# Quota Widget (es)

[English](../README.md) · [Português](README.pt-BR.md)

Widget flotante para Windows que reúne las cuotas de uso de tus IA en un solo lugar, con barras y cuenta regresiva hasta la renovación. Soporta **Claude**, **ChatGPT (Codex)**, **Command Code** y **Ollama**, y se aceptan nuevos proveedores.

- **Instalar:** descarga `Quota-Widget-Setup-<versión>.exe` desde la página de [Releases](https://github.com/edilsondjr/ai-quota-widget/releases). El instalador no está firmado, así que SmartScreen puede avisar; haz clic en "Más información" y "Ejecutar de todas formas".
- **Configurar:** haz clic en ⚙ en el widget para elegir qué se muestra, el intervalo de actualización, las claves de API (se guardan cifradas por Windows), el idioma (English/Español/Português) y el inicio con Windows.
- **Compilar desde el código:** `npm install` y `npm run dist` (Node 20+, en Windows).
- **Aviso:** las rutas usadas no son oficiales y pueden cambiar. Úsalo solo con tus propias cuentas y bajo tu propio riesgo.

La documentación completa (en inglés) está en el [README](../README.md).
